- 产品名：PromptBox
- 状态：草稿（产品名、目标用户已确认；依赖清单讨论中）

- 周期：一人一周（D1–D7）

- 配套：[产品框架](framework.md) · [原型](prototype.html)

## 1. 一句话

给重度 AI 用户的提示词与 Skill 资产库：在一个地方管理提示词、Skill、CLAUDE.md / AGENTS.md，带版本历史，一键复制，或导出成各工具能直接用的文件。

## 2. 问题

**第 0 号用户（我自己）的真实情况：**

- 同一个 Skill 有两份：维护源在 `产品经理skill/`，Suo 项目里放的是快照。改了一边要手动同步，时间一长就不确定哪份最新。
- WorkBuddy 和 Codex 的技能目录靠软链互相共享，这是自己搭出来的"土办法"。
- 常用提示词散落在备忘录、聊天记录和各个项目文件里，要用的时候靠翻。

**外部证据：** 待补（D1 上午 30 分钟，在小红书、V2EX 搜"提示词管理""skill 管理"，截 3–5 条真实吐槽）。

**现有替代做法：** 备忘录 / Notion、手动复制、软链、各工具各存一份。

## 3. 目标用户（已确认）

| 优先级 | 人群 | 特征 |
|---|---|---|
| 主要 | 多工具重度用户 | 同时用 2 个以上 AI 工具（Claude Code、Codex、Cursor、网页版 ChatGPT / Claude 等），自己写过 Skill 或规则文件 |
| 次要 | 网页端重度用户 | 有 20 条以上反复使用的提示词 |
| 不面向 | 轻度用户 | 偶尔用 AI，没有沉淀提示词的需求 |

## 4. 核心场景

1. **存**：把散落各处的提示词、Skill 粘贴或拖进来，打上标签。
2. **找和用**：搜索，填变量，复制，粘贴到 AI 工具里。
3. **改**：迭代提示词时自动留版本，可以对比两版差异、回退到旧版。
4. **带走**：导出成 `SKILL.md` / `CLAUDE.md` / `AGENTS.md`，放进工具目录就能用。
5. **备份**：全量导出 / 导入，换浏览器或换电脑不丢数据。

## 5. MVP 范围

### P0（一周内必须完成）

| 功能 | 说明 | 验收标准 |
|---|---|---|
| 条目管理 | 新建、编辑、删除；字段：标题、正文（Markdown）、类型（提示词 / Skill / 规则文件）、标签、备注 | 刷新页面后数据仍在 |
| 搜索与筛选 | 按标题、正文、标签搜索；按类型和标签筛选 | 输入即出结果 |
| 一键复制 | 卡片和详情页都能复制 | 复制后有明确反馈 |
| 变量模板 | 识别正文中的 `{{变量}}`，复制前弹窗填写 | 没有变量时直接复制，不弹窗 |
| 版本历史 | 每次保存生成一个版本；任选两版并排对比差异；可回退 | 回退本身也生成新版本，不丢历史 |
| 单条导出 | 导出为 `SKILL.md`（自动生成 name / description 头信息）、`CLAUDE.md`、`AGENTS.md`、普通 `.md` | 导出 `SKILL.md` 时要求填英文短名（小写字母、数字、连字符） |
| 全量备份 | 导出 / 导入 JSON；把 `.md` 文件拖进页面即新建条目 | 导出再导入后数据一致 |
| 示例数据 | 首次打开预置 5–8 条示例 | 面试官 10 秒内看懂产品是做什么的 |
| 反馈入口 | 页面角落常驻"提反馈"链接，指向 GitHub Issues；主要反馈靠微信私聊收集 | 点击能打开反馈页 |

### P1（有余力再做）

- `⌘K` 快速搜索
- 置顶 / 收藏
- 暗色模式
- 批量打标签

## 6. 暂不做（及原因）

| 不做 | 原因 |
|---|---|
| 账号登录、云同步 | 一周做不完。纯本地反而让用户放心：数据不离开浏览器。代价是换设备要手动导出导入。 |
| 直接写入本地工具目录（自动同步） | 浏览器的文件夹读写接口只在部分浏览器可用，且需要逐次授权；完整同步需要 CLI 或桌面端。先用"导出文件"验证需求，反馈强烈再做。 |
| 社区、公开分享 | 需要后端、内容审核和冷启动运营。先验证个人管理需求是否成立。 |
| 提示词优化 / 生成 | 模型厂商已提供免费的同类功能，差异化弱；还要接 API，涉及费用和 Key 安全。 |
| 多模型效果对比 | 需要接多家 API、产生费用，放到下一阶段。 |

## 9. 技术方案

- 纯前端单页应用；数据存在浏览器本地（IndexedDB）；无后端、无登录、不调用任何 AI 接口。
- 技术栈（候选）：Vite + React + TypeScript；版本对比用开源 diff 库。依赖清单在 D1 开工前确认。
- 部署：静态托管，D5 用手机 4G 实测国内访问后选定。
- 开源：GitHub，MIT 协议。README 按复盘结构写，兼作作品集页面。

## 11. 风险

| 风险 | 应对 |
|---|---|
| 国内打不开或很慢 | D5 实测，不行就换平台 |
| 用户清缓存或用无痕模式导致数据丢失 | 首页提示定期导出；设置页显示上次备份时间 |
| 正文里本来就有 `{{ }}`（比如模板代码） | 变量弹窗里可以选择"原样复制" |
| 开发超时 | 先砍 P1，再把导出格式缩减到 `SKILL.md` 和 `.md` |
