发现

PromptBox 的核心。不用你整理，它从你和各个 AI 的对话里找出你反复在说的话。新用户第一次打开就落在这里。

  1. 1侧栏第一项，数字是待处理的候选数。
  2. 2记录来源只显示工具图标，鼠标移上去看名称和对话数；虚线圈是还没添加的。右边的按钮管理来源。真实产品用各工具自己的图标。
  3. 3刷新按钮：只扫描上次之后新增的对话。全部在浏览器里计算，不上传。
  4. 4候选分两类：提示词（重复的任务）和规则（重复的纠正），按出现次数排序。图标：气泡是提示词，图钉是规则，全站通用。
  5. 5和库里已有内容相似时会标出来，保存时合并进已有条目，不会重复。
  6. 6存之前可以改名、改类型、打标签。忽略过的不会再出现。点左边的两条规则看规则长什么样。
  7. 7模板：每次都一样的部分保留，不一样的部分变成 {{变量}}；下划线部分来自你的纠正。
  8. 8AI 精修是可选的，在设置里填了 Key 才会用，只发送这几句原话。没填 Key 时用规则起名。
  9. 9原话是证据：能看到候选从哪几次对话里来，存进库后也保留。

# 需求文档评审

按以下顺序评审用户提供的需求文档：

1. 目标：是否写清楚要解决谁的什么问题
2. 范围：做什么、不做什么是否明确
3. 流程：主流程和异常流程是否完整
4. 验收：每条需求能否被测试验证

输出：先给总体结论，再按「问题 / 位置 / 建议」逐条列出。
