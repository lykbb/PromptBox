# PromptBox 产品框架 v0.1

- 状态：草稿，待确认
- 日期：2026-10-16
- 配套：[PRD](PRD.md) · [原型](prototype.html)（用浏览器打开，可点击）

---

## 1. 设计原则

1. **找到就能用**：从打开到复制，最少两步。
2. **一个操作只在一个地方**：同一个按钮不在两处重复出现。快捷键和拖拽不算重复。
3. **数据在本地，随时带得走**：不登录、不上传，随时能导出成文件。
4. **不让用户操心保存**：内容自动保存，版本自动生成。

## 2. 页面结构

```
PromptBox（单页应用）
├── 主界面（三栏）
│   ├── 侧栏：全部 / 类型 / 标签 · 导入 · 备份 · 反馈 · GitHub
│   ├── 列表：搜索 · 新建 · 条目列表 · 首次提示条
│   └── 详情：复制 · 导出 · 历史 · 更多（删除）· 类型 · 标签 · 备注 · 编辑区
├── 弹窗
│   ├── 复制：填写变量
│   ├── 版本历史与对比
│   ├── 导出
│   ├── 导入确认
│   └── 备份
└── 状态
    ├── 首次打开：8 条示例 + 提示条
    ├── 空状态 / 搜索无结果
    └── 拖入文件
```

## 3. 主界面为什么用三栏

| 方案 | 适合 | 问题 |
|---|---|---|
| 卡片墙（提示词社区常见） | 浏览、发现别人的内容 | 看全文要进详情页，来回跳转 |
| 三栏：筛选 / 列表 / 详情（备忘录类工具常见） | 管理自己的内容：找、看、改、复制 | 窄屏要改成两层 |

PromptBox 的核心是管理和使用**自己的**内容，所以选三栏。窄屏（小于 768px）时变成「列表 → 详情」两层。

## 6. 核心流程

1. **找和用**：搜索或筛选 → 选中 → 复制 →（有变量）填写 → 复制结果 → 粘贴到 AI 工具
2. **存**：新建 → 写标题和正文 → 选类型、打标签（全程自动保存）
3. **改**：编辑 → 离开这条内容 → 自动生成新版本 → 在历史里对比或恢复
4. **带走**：导出 → 选格式 →（SKILL.md）填短名和描述 → 下载或复制 → 放进工具目录
5. **迁移**：备份 → 导出 .json → 在新浏览器打开 PromptBox → 导入 → 确认

## 7. 关键规则

**保存与版本**

- 正文改动后自动保存（停止输入约 0.5 秒），没有保存按钮。
- 离开一条内容时（切换条目、新建、打开历史、关闭或切走页面），如果正文和最近一个版本不同，自动生成新版本。
- 历史只记录正文。改标题、标签、备注不生成版本。
- 恢复：把所选版本的正文设为当前正文，同时生成一个新版本（"从 v2 恢复"）。原有历史不删除。

**变量**

- 写法：`{{名称}}`。名称 1–20 个字，不能包含花括号。
- 同名变量只填一次；输入框按变量在正文里出现的顺序排列。
- 没填的变量保留原样。

**复制和删除**

- 复制的是编辑区当前内容，复制后提示"已复制"。
- 删除后立即从列表移除，底部提示条 6 秒内可撤销；超时后连同历史版本一起删除。

**导入**

- 自动识别：`SKILL.md` 或带 name / description 头信息的 .md → Skill；`CLAUDE.md`、`AGENTS.md` → 规则文件；其他 .md → 提示词；.json → 备份。
- 备份里 ID 已存在的条目跳过，不覆盖。
- 不支持的文件列出来标"不支持"，不影响其他文件。确认后才写入。

**导出 SKILL.md**

- 英文短名只能用小写字母、数字、连字符，最长 64 个字符，不以连字符开头或结尾。描述不能为空。（编码时对照官方规范再核对一遍）
- 导出时填的短名和描述存回这条内容，下次不用再填。

**示例数据和备份提醒**

- 首次打开写入 8 条示例，其中「周报生成」带 3 个历史版本，用来演示对比。
- 「清除示例」只删示例，不动用户自己的内容。
- 从未备份或距上次备份超过 7 天，且之后有改动时，侧栏「备份」旁显示提醒点。

## 8. 数据结构

**条目（Item）**

| 字段 | 说明 |
|---|---|
| id | 唯一标识 |
| type | 提示词 / Skill / 规则文件 |
| title | 标题 |
| content | 正文（当前内容） |
| tags | 标签列表 |
| note | 备注 |
| skillName / skillDescription | 英文短名和描述（导出 SKILL.md 用，任何类型都可以有） |
| isSample | 是否示例 |
| createdAt / updatedAt | 创建、修改时间 |

**版本（Version）**

| 字段 | 说明 |
|---|---|
| id | 唯一标识 |
| itemId | 属于哪条内容 |
| number | 版本号：1、2、3…… |
| content | 当时的正文 |
| source | 来源：编辑 / 恢复 / 导入 |
| createdAt | 生成时间 |

**设置**：上次备份时间、提示条是否已关闭。

**备份文件**：`{ app, formatVersion, exportedAt, items, versions }`，文件名带日期，比如 `promptbox-backup-2026-10-16.json`。

## 9. 技术分层

- **界面层**：主界面三栏 + 5 个弹窗。
- **逻辑层**：纯函数，包括变量识别、导出格式、导入识别、版本差异、搜索。方便写自动测试。
- **存储层**：浏览器本地数据库，三张表：条目、版本、设置。

## 10. 相对 PRD 的调整（确认后同步进 PRD）

1. **复制只放在详情顶部**：PRD 原写"卡片和详情页都能复制"，按"一个操作只在一个地方"调整。列表选中时按回车也能复制。
2. **保存改为自动**：PRD 原写"每次保存生成一个版本"，改为自动保存，离开这条内容时自动生成版本。用户不会因为忘记保存而丢内容，也不会每打一个字就多一个版本。
3. **Skill 多两个字段**：英文短名和描述，这是导出 SKILL.md 的必填项。导入 SKILL.md 时自动填好。
4. **导入合并成一个入口**：.md 和备份 .json 都从侧栏「导入」进，自动识别。
5. **导出弹窗增加两条提示**：文件放在哪里才能生效；正文里有变量时提醒会原样保留。
6. **弹窗只有一个关闭按钮**：右上角 ×，底部只放前进操作。
